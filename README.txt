DANIEL COSTA GASTRONOMIA — V9

Esta é a primeira versão com backend e banco de dados reais.

COMO RODAR:
1) Instale Python 3.
2) Abra o terminal nesta pasta.
3) Rode:
   python -m venv .venv
4) Ative o ambiente:
   Windows: .venv\Scripts\activate
   macOS/Linux: source .venv/bin/activate
5) Instale:
   pip install -r requirements.txt
6) Crie o administrador:
   python setup_admin.py
7) Inicie:
   python app.py
8) Acesse:
   http://127.0.0.1:5000
